Demo Reveal.js

Plantilla de referencia para el proyecto diapo_creator

Cada presentación en reveal.js es un único archivo index.html acompañado de un styles.css y, opcionalmente, una carpeta assets/ para imágenes.

Las dependencias se cargan por CDN — no hay paso de build.

Estructura básica de una diapositiva

Cada <section> dentro de <div class="slides"> es una diapositiva. La navegación es horizontal por defecto; stacks verticales se logran anidando <section>.

<section id="mi-slide">
  <h2>Título de la diapositiva</h2>
  <p>Contenido...</p>
</section>

Layouts de dos y tres columnas

Usa display: grid directamente con estilos inline. Cada slide tiene proporciones distintas, por eso no usamos clases utilitarias globales.

Imágenes y assets

Las imágenes viven en assets/ dentro de la carpeta de la presentación. Se referencian con rutas relativas, igual que en cualquier HTML estático.

<img
  src="assets/grafico.png"
  alt="descripcion"
  style="width: 100%;">

Buenas prácticas:

  • Usa object-fit: contain dentro de un contenedor flex
  • Genera los gráficos con generar_grafico_lamina_X.py
  • Formato PNG para figuras con texto

Cómo trabajar con reveal.js

Desarrollo local

Servir la carpeta actual con cualquier servidor estático:

python3 -m http.server 8080
# luego abrir http://localhost:8080
Generar PDF / screenshots

Usa decktape para producir el PDF de la presentación y screenshots de cada lámina.

npx decktape reveal \
  "http://localhost:8080/index.html" \
  output.pdf --screenshots
Verificación de overflow

Antes de exportar, revisa cada lámina con el script del skill revealjs:

node .agents/skills/revealjs/scripts/check-overflow.js \
  index.html
